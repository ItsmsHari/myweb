## PART 2: BASIC IMAGE EDITING TASKS

### 2.1 Resizing Images

Using GIMP:
  1. File → Open Image
  2. Image → Scale Image
  3. Set new dimensions (width x height)
  4. Click Scale
  5. File → Export As → Save

Using ImageMagick (Command Line):
  convert original.jpg -resize 800x600 resized.jpg
  convert original.jpg -resize 50% resized.jpg

### 2.2 Cropping Images

Using GIMP:
  1. Select Rectangle Select Tool
  2. Drag to select area to keep
  3. Image → Crop to Selection
  4. File → Export As

Using ImageMagick:
  convert original.jpg -crop 800x600+10+10 +repage cropped.jpg

### 2.3 Compressing Images

Using GIMP:
  1. File → Export As
  2. Choose JPEG or PNG format
  3. For JPEG: Set quality (85 recommended)
  4. For PNG: Compression level (9 is max)

Using ImageMagick:
  convert original.jpg -quality 85 compressed.jpg
  convert original.png -strip -quality 85 compressed.png

### 2.4 Format Conversion

Using ImageMagick:
  convert input.jpg output.png
  convert input.png output.gif
  convert input.jpg output.webp
  convert input.jpg output.bmp

### 2.5 Adding Text to Images

Using GIMP:
  1. Select Text Tool
  2. Click on image where text should go
  3. Type text
  4. Adjust font, size, color
  5. File → Export As

Using ImageMagick:
  convert input.jpg -pointsize 30 -draw "text 10,50 'Hello'" output.jpg

### 2.6 Adjusting Brightness & Contrast

Using GIMP:
  1. Colors → Brightness-Contrast
  2. Adjust sliders
  3. Click OK
  4. File → Export As

Using ImageMagick:
  convert input.jpg -brightness-contrast 10x20 output.jpg

### 2.7 Rotating Images

Using GIMP:
  1. Image → Transform → Rotate 90° clockwise/counter-clockwise
  2. File → Export As

Using ImageMagick:
  convert input.jpg -rotate 90 output.jpg

## PART 3: BATCH IMAGE PROCESSING

### 3.1 Batch Resize Multiple Images

Using ImageMagick (Windows PowerShell):
```powershell
# Resize all JPG images in folder
Get-ChildItem "C:\images\*.jpg" | ForEach-Object {
    $outputName = $_.BaseName + "_resized.jpg"
    convert "$_.FullName" -resize 800x600 "C:\output\$outputName"
}
```

Using ImageMagick (Linux/Mac):
```bash
# Resize all images in current directory
for file in *.jpg; do
    convert "$file" -resize 800x600 "resized_$file"
done
```

### 3.2 Batch Convert Format

Windows PowerShell:
```powershell
# Convert all PNG to JPG
Get-ChildItem "C:\images\*.png" | ForEach-Object {
    $outputName = $_.BaseName + ".jpg"
    convert "$_.FullName" "$outputName"
}
```

### 3.3 Batch Compress Images

```bash
# Compress all JPG files
for file in *.jpg; do
    convert "$file" -quality 85 "compressed_$file"
done
```

## PART 4: IMAGE EDITING FOR WEB APPLICATIONS

### 4.1 Optimal Image Sizes for Web

Header Images: 1200 x 400 pixels (3:1 ratio)
Thumbnails: 200 x 200 to 300 x 300 pixels
Product Images: 600 x 600 to 800 x 800 pixels
Banner Images: 1920 x 1080 or 1280 x 720 pixels
Avatar/Profile: 150 x 150 to 400 x 400 pixels
Social Media:
  - Facebook: 1200 x 630 pixels
  - Twitter: 1200 x 675 pixels
  - Instagram: 1080 x 1080 pixels (square)

### 4.2 Image Formats for Web

PNG:
  - Best for: Graphics, logos, transparent backgrounds
  - Advantages: Lossless, supports transparency
  - Disadvantage: Larger file size
  - Use case: UI elements, icons

JPG/JPEG:
  - Best for: Photographs and complex images
  - Advantages: Small file size, good quality
  - Disadvantage: Lossy compression, no transparency
  - Use case: Photos, background images

WebP:
  - Best for: Modern web browsers
  - Advantages: Smaller size than JPG/PNG
  - Disadvantage: Limited browser support (older browsers)
  - Use case: Progressive web apps

GIF:
  - Best for: Animated images
  - Advantages: Animation support
  - Disadvantage: Limited colors, large file size
  - Use case: Simple animations

### 4.3 File Size Optimization

Recommended File Sizes:
  - Homepage banner: < 500 KB
  - Product image: < 300 KB
  - Thumbnail: < 50 KB
  - Icon/Logo: < 20 KB
  - Avatar: < 100 KB

Optimization Steps:
  1. Choose appropriate format (JPG for photos, PNG for graphics)
  2. Resize to required dimensions
  3. Compress using quality setting (85% for JPG recommended)
  4. Use online tools: TinyPNG, Compressor.io, Imagemin

## PART 5: IMAGE EDITING IN JAVA

### 5.1 Java Libraries for Image Processing

1. BufferedImage (Built-in Java API)
```java
import javax.imageio.ImageIO;
import java.awt.image.BufferedImage;
import java.io.File;

public class ImageProcessor {
    
    // Resize image
    public static BufferedImage resizeImage(String inputPath, 
            int width, int height) throws Exception {
        BufferedImage originalImage = ImageIO.read(new File(inputPath));
        BufferedImage resizedImage = new BufferedImage(width, height, 
            BufferedImage.TYPE_INT_RGB);
        
        java.awt.Graphics2D g2d = resizedImage.createGraphics();
        g2d.drawImage(originalImage, 0, 0, width, height, null);
        g2d.dispose();
        
        ImageIO.write(resizedImage, "jpg", new File("resized.jpg"));
        return resizedImage;
    }
    
    // Rotate image
    public static void rotateImage(String inputPath, double angle) 
            throws Exception {
        BufferedImage originalImage = ImageIO.read(new File(inputPath));
        int width = originalImage.getWidth();
        int height = originalImage.getHeight();
        
        BufferedImage rotatedImage = new BufferedImage(height, width, 
            BufferedImage.TYPE_INT_RGB);
        
        java.awt.Graphics2D g2d = rotatedImage.createGraphics();
        g2d.rotate(Math.toRadians(angle), height / 2, width / 2);
        g2d.drawImage(originalImage, 0, 0, null);
        g2d.dispose();
        
        ImageIO.write(rotatedImage, "jpg", new File("rotated.jpg"));
    }
}
```

3. Thumbnailator Library
```xml
<dependency>
    <groupId>net.coobird</groupId>
    <artifactId>thumbnailator</artifactId>
    <version>0.4.14</version>
</dependency>
```

Usage:
```java

// Create thumbnail
Thumbnails.of(new File("input.jpg"))
    .size(200, 200)
    .toFile(new File("thumbnail.jpg"));

// Resize image
Thumbnails.of(new File("input.jpg"))
    .size(800, 600)
    .toFile(new File("resized.jpg"));

// Compress image
Thumbnails.of(new File("input.jpg"))
    .outputQuality(0.85)
    .toFile(new File("compressed.jpg"));
```

## PART 6: PRACTICAL EXAMPLES

### 6.1 Spring Boot Image Upload & Process

```java
@RestController
@RequestMapping("/api/images")
public class ImageController {
    
    @PostMapping("/upload")
    public ResponseEntity<?> uploadImage(
            @RequestParam("file") MultipartFile file) {
        
        try {
            // Save original
            String originalName = file.getOriginalFilename();
            file.transferTo(new File("uploads/" + originalName));
            
            // Create thumbnail using Thumbnailator
            Thumbnails.of(new File("uploads/" + originalName))
                .size(200, 200)
                .toFile(new File("uploads/thumb_" + originalName));
            
            return ResponseEntity.ok("Image uploaded successfully");
            
        } catch (Exception e) {
            return ResponseEntity.badRequest()
                .body("Upload failed: " + e.getMessage());
        }
    }
}
```

### 6.2 Image Validation

```java
public class ImageValidator {
    
    public static boolean isValidImage(MultipartFile file) {
        // Check file size (max 5MB)
        if (file.getSize() > 5 * 1024 * 1024) {
            return false;
        }
        
        // Check file type
        String contentType = file.getContentType();
        return contentType.equals("image/jpeg") || 
               contentType.equals("image/png") || 
               contentType.equals("image/gif");
    }
    
    public static void validateImageDimensions(BufferedImage img, 
            int minWidth, int minHeight) throws Exception {
        if (img.getWidth() < minWidth || img.getHeight() < minHeight) {
            throw new Exception("Image too small");
        }
    }
}
```

## PART 7: BEST PRACTICES

### 7.1 Image Editing Best Practices

1. Always keep original files
   - Work on copies, keep backups
   - Never overwrite original images

2. Use consistent naming
   - product_001.jpg
   - thumbnail_product_001.jpg
   - resized_product_001.jpg

3. Maintain aspect ratio when resizing
   - Use proportional scaling
   - Avoid distorting images

4. Compress images appropriately
   - JPEG quality: 85 is usually optimal
   - Balance between quality and file size

5. Use appropriate formats
   - Photos: JPG
   - Graphics/Icons: PNG
   - Animations: GIF
   - Modern web: WebP

### 7.2 Web Image Best Practices

1. Optimize file sizes
   - JPG: 85% quality
   - PNG: 8-bit color when possible
   - Use WebP for modern browsers

2. Use appropriate dimensions
   - Don't serve oversized images
   - Create multiple sizes for responsive design

3. Implement lazy loading
   - Load images only when visible
   - Improves page performance

4. Use CDN for image delivery
   - Reduce server load
   - Faster delivery to users

5. Add alt text to images
   - Improves accessibility
   - Better SEO

## PART 9: DIGITAL MARKETING GUIDE

### 9.1 What is Digital Marketing?

Digital Marketing refers to marketing strategies and tactics conducted through 
digital channels (internet, social media, email, mobile apps) to reach and 
engage customers online.

### 9.2 Key Digital Marketing Channels

1. SEARCH ENGINE MARKETING (SEM)
   - SEM Components:
     * SEO (Search Engine Optimization)
     * PPC (Pay-Per-Click Advertising)
   - Objective: Increase visibility in search results
   - Tools: Google Ads, Google Search Console, Bing Ads
   - Best for: High-intent customers searching for solutions

2. SOCIAL MEDIA MARKETING (SMM)
   - Platforms: Facebook, Instagram, Twitter, LinkedIn, TikTok, YouTube
   - Strategies:
     * Content Marketing
     * Community Management
     * Influencer Partnerships
     * Social Ads
   - Benefits: Brand awareness, customer engagement, relationship building

3. EMAIL MARKETING
   - Objective: Direct communication with customers
   - Tactics:
     * Newsletter campaigns
     * Promotional emails
     * Abandoned cart recovery
     * Customer retention
   - Tools: Mailchimp, ConvertKit, ActiveCampaign
   - ROI: $42 per $1 spent (average)

4. CONTENT MARKETING
   - Types: Blog posts, videos, infographics, whitepapers, case studies
   - Objective: Provide value and attract customers
   - Benefits: SEO improvement, thought leadership, trust building
   - Distribution: Website, social media, email

5. PAID ADVERTISING
   - Platforms:
     * Google Ads (Search, Display, Shopping)
     * Facebook/Instagram Ads
     * LinkedIn Ads
     * Programmatic Advertising
   - Cost Model: CPC, CPM, CPA, ROAS

6. INFLUENCER MARKETING
   - Types: Micro-influencers, macro-influencers, celebrities
   - Benefits: Authentic endorsements, expanded reach
   - Platforms: Instagram, YouTube, TikTok
   - ROI: Strong but varies by influencer selection

7. VIDEO MARKETING
   - Formats: YouTube videos, short-form video (TikTok), Live streaming
   - Benefits: Higher engagement, better retention
   - Optimization: Proper titles, descriptions, thumbnails, tags

8. AFFILIATE MARKETING
   - Model: Commission-based marketing
   - Benefits: Performance-based, low upfront cost
   - Tools: Affiliate networks, tracking software
   - Commission rates: 5-50% depending on product

### 9.3 Digital Marketing Metrics & KPIs

### Traffic Metrics
   - Impressions: Number of times content displayed
   - Clicks: Number of clicks on links/ads
   - Click-Through Rate (CTR): Clicks / Impressions
   - Session: User's complete website visit
   - Unique Visitors: Individual users visiting website

### Engagement Metrics
   - Bounce Rate: % of visitors who leave without action
   - Time on Page: Average time spent on page
   - Pages per Session: Average pages viewed per visit
   - Scroll Depth: How far users scroll down page
   - Video Watch Time: Minutes watched on video

### Conversion Metrics
   - Conversion Rate: % of visitors who complete desired action
   - Lead Generation Rate: Leads captured per 100 visitors
   - Cost Per Lead (CPL): Total ad spend / Leads generated
   - Cost Per Acquisition (CPA): Total ad spend / Sales
   - Return on Ad Spend (ROAS): Revenue / Ad spend

### Social Media Metrics
   - Reach: Number of unique users who see content
   - Impressions: Total number of content displays
   - Engagement Rate: (Likes + Comments + Shares) / Followers
   - Share of Voice: Your mentions vs competitors
   - Sentiment: Positive, negative, neutral mentions

### Email Marketing Metrics
   - Open Rate: % of subscribers who open email (Target: 20-30%)
   - Click Rate: % who click links (Target: 2-5%)
   - Unsubscribe Rate: % who unsubscribe (Target: < 0.5%)
   - Conversion Rate: % who complete desired action
   - List Growth Rate: Rate of subscriber increase

### 9.4 Digital Marketing Strategy Framework

Step 1: Define Goals & Objectives (SMART)
   - Increase website traffic by 50% in 6 months
   - Generate 1000 leads per month
   - Achieve 3% email open rate
   - Improve brand awareness by 40%

Step 2: Identify Target Audience
   - Demographics: Age, gender, location, income
   - Psychographics: Interests, values, lifestyle
   - Behavioral: Online habits, purchase patterns
   - Create buyer personas

Step 3: Competitor Analysis
   - Identify main competitors
   - Analyze their marketing strategies
   - Identify gaps and opportunities
   - Benchmark against industry standards

Step 4: Choose Digital Channels
   - Evaluate each channel's fit
   - Allocate budget across channels
   - Prioritize high-ROI channels
   - Create channel mix

Step 5: Create Content Strategy
   - Content types: Blog, video, infographic, email
   - Content calendar: Publishing schedule
   - SEO optimization: Keywords, meta tags
   - Storytelling: Engaging narratives

Step 6: Execute Campaigns
   - Design and launch campaigns
   - Implement tracking pixels
   - Set up analytics
   - Configure automated workflows

Step 7: Monitor & Measure
   - Track KPIs daily/weekly
   - Create performance dashboards
   - Monitor competitor activity
   - Analyze conversion paths

Step 8: Optimize & Improve
   - A/B testing on ad copy, images, landing pages
   - Adjust targeting and bidding
   - Refine messaging based on performance
   - Continuous improvement process

### 9.6 SEO (Search Engine Optimization)

On-Page SEO:
   - Keyword research and placement
   - Title tags (50-60 characters)
   - Meta descriptions (150-160 characters)
   - Header tags (H1, H2, H3)
   - URL structure (descriptive, lowercase)
   - Internal linking strategy
   - Image optimization and alt text
   - Page speed optimization

Off-Page SEO:
   - Backlink building (quality > quantity)
   - Guest posting on relevant sites
   - Directory submissions
   - Brand mentions
   - Social signals

Technical SEO:
   - XML sitemap
   - Robots.txt file
   - Schema markup
   - Mobile responsiveness
   - HTTPS security
   - Site speed (Core Web Vitals)
   - Crawlability

SEO Tools:
   - Google Search Console (free)
   - Google Analytics 4 (free)
   - SEMrush, Ahrefs (paid)
   - Yoast SEO (WordPress plugin)

### 9.8 Email Marketing Strategy

Email List Building:
   - Landing pages: Attractive lead magnets
   - Pop-ups: Exit intent, scroll depth triggered
   - Forms: Subscribe forms on website
   - Lead magnets: Free guides, templates, tools

Email Campaign Types:

Welcome Series (Automation):
   - Email 1 (Day 1): Welcome + benefit statement
   - Email 2 (Day 3): Valuable content/offer
   - Email 3 (Day 7): Product/service introduction

Newsletter:
   - Frequency: Weekly or bi-weekly
   - Content: Mix of articles, tips, promotions
   - Segmentation: Different content for segments
   - CTAs: Clear call-to-action

Promotional Email:
   - Frequency: As needed (promotions, sales)
   - Personalization: Recipient name, purchase history
   - Subject line: Urgency, benefit-driven
   - A/B testing: Subject line, send time, content

Abandoned Cart Recovery:
   - Email 1: Sent 1 hour after abandonment
   - Email 2: 24 hours later with incentive
   - Email 3: 72 hours later with last chance message

Re-engagement Campaign:
   - Target: Inactive subscribers (6+ months)
   - Message: "We miss you" approach
   - Incentive: Special offer to reactivate
   - Final: Unsubscribe if no engagement

Email Best Practices:
   - Mobile responsive design
   - Personalization: Name, segment-specific content
   - Clear subject lines (40-50 characters)
   - Preheader text optimization
   - Single CTA or limited options
   - Test send time (best is 10 AM Tuesday)
   - Unsubscribe link always visible
   - Spam compliance (CAN-SPAM, GDPR, CCPA)
